# もぐら叩き

30秒で何点取れるかを競う、3×3のもぐら叩きゲームです。HTMLファイル1つで動きます。

## 遊び方

`index.html` をブラウザで開き、「スタート」を押します。穴から顔を出したもぐらをクリック（スマホではタップ）すると得点が入ります。

- ふつうのもぐら：1点
- 金のもぐら：3点（ときどき出現・引っ込むのが早い）
- 連続で叩くとコンボ表示
- 残り時間が少ないほど、もぐらが引っ込むのが早くなる
- ベスト記録はブラウザに保存

## 特徴

- 外部ライブラリなし（HTML / CSS / JavaScript のみ）
- もぐら・ハンマー・エフェクトはすべてSVGとCSSで描画
- 効果音は Web Audio API で合成（音声ファイル不要）、画面右上で消音可能
- PC・スマホ両対応

## GitHub Pagesで公開する

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`・フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます
